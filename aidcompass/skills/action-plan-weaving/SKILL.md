# Action Plan Weaving

1. Start with the highest-priority need and lowest-friction credible action.
2. Write one best first step with action, reason, resource, and timing.
3. Plan A should use the strongest match or complementary resources.
4. Plan B must differ in resource, delivery mode, timing, or pathway.
5. Keep each plan short enough to act on; avoid a giant directory dump.
6. Build a combined document backpack. Use “if available” unless the record makes it mandatory.
7. Preserve all source records exactly.
8. Include confidence and verification notes.
9. Use `references/plan-pattern.md` as the shape and validate with `scripts/validate_plan.py`.
