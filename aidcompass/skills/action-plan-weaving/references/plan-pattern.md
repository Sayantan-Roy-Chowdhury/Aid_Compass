# Plan pattern

- Headline: names the user's goal, not the system.
- Best first step: one action that can start next.
- Best matches: usually two to five resources.
- Plan A: primary route with ordered steps.
- Plan B: fallback triggered by a clear condition.
- Document backpack: short combined checklist.
- Outreach: at most three drafts.
- Confidence notes: source freshness, availability, and eligibility limits.
- Shareable summary: neutral paragraph suitable for a trusted helper.
